# Sanctum Protocol

Institutional website for `sanctumprotocol.org`.

Sanctum Protocol is the ontology, governance, interoperability, and research
layer for the Sanctum ecosystem. It is separate from Sanctum Studio and runs on
strict local port `5192`.

## Development

```bash
npm install
npm run dev
```

Local URL:

```text
http://127.0.0.1:5192/
```

## Build

```bash
npm run build
npm run preview
```
